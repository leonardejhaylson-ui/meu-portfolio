# Portfólio — Jhaylson Conceição

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript para apresentar meus projetos, tecnologias e evolução como desenvolvedor.

## Sobre

O site reúne informações profissionais e projetos em uma interface responsiva, sem framework frontend. A implementação foi mantida propositalmente simples para exercitar fundamentos da Web.

## Funcionalidades

- layout responsivo;
- tema claro/escuro com preferência salva no navegador;
- navegação adaptada para desktop e mobile;
- projetos renderizados via JavaScript;
- filtros de projetos;
- projeto em destaque;
- animações com respeito a `prefers-reduced-motion`;
- elementos de acessibilidade como skip link, estados de foco e atributos ARIA;
- metadados básicos para compartilhamento e mecanismos de busca.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Executando localmente

Não há etapa de build. Clone o repositório e abra `index.html` no navegador, ou sirva a pasta com um servidor HTTP local.

```bash
git clone https://github.com/leonardejhaylson-ui/meu-portfolio.git
cd meu-portfolio
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Objetivo

Este projeto é a interface pública do meu portfólio e também registra minha prática com fundamentos de frontend, responsividade, acessibilidade e organização de conteúdo profissional.

O conteúdo do site deve evoluir junto com meus projetos e com meu foco atual em desenvolvimento backend e aplicações com IA.
